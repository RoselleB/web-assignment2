# Student Portal

A student portal built with Next.js, TypeScript, and Tailwind CSS.

## Features
- View student information and statistics.
- Search students by name.
- Show and hide student details.
- Add and remove students.
- Clear all students.

## Team Contributions
- **Member A:** Navbar, Footer, StatsPanel.
- **Zara Qadri:** Student data, StudentList, StudentCard.
- **Nathan Foran:** StudentPortal, SearchBox, AddStudent.

## How to Run

```bash
npm install
npm run dev
```

Open http://localhost:3000 in your browser.
